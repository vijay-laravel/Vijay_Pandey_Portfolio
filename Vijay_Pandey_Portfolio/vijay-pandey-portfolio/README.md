# Vijay Pandey — Developer Portfolio

A responsive, animated React + Vite portfolio website.

## Requirements
- Node.js 18.18+ (Node.js 20 LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```
The production website is generated in the `dist/` folder.

## Deploy to Vercel (free Hobby plan for a personal portfolio)
1. Extract this ZIP.
2. Push the project folder to a new GitHub repository.
3. In Vercel, choose **Add New → Project** and import that GitHub repository.
4. Keep the framework preset as **Vite**.
5. Build command: `npm run build`
6. Output directory: `dist`
7. Click **Deploy**.

No environment variables or backend server are required.
